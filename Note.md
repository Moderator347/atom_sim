# Техническая записка (Note)

Проект: **Crystal Lattice Visualization** — веб-приложение для интерактивной 3D-визуализации
кристаллических решёток и моделирования химических реакций с участием нейросетевого
предсказания межатомных связей.

---

## 1. Тема

Интерактивная 3D-визуализация кристаллических структур химических элементов с интеллектуальным
анализом атомных связей и симуляцией реакций на основе машинного обучения.

## 2. Проблема

Традиционные средства изучения кристаллографии и химии твёрдого тела (учебники, статические
рисунки, локальные пакеты вроде VESTA/Ovito) либо не интерактивны, либо требуют установки
громоздкого ПО и специальных знаний. При этом:

- учащимся и исследователям сложно интуитивно понять, как расположение атомов в решётке
  определяет её свойства;
- классические геометрические алгоритмы поиска связей («по порогу расстояния») плохо работают
  на смешанных системах, где разные пары элементов имеют разную химию связи;
- моделирование «что будет, если внедрить атом одного вещества в решётку другого» в реальном
  времени в браузере практически недоступно.

## 3. Актуальность

- Цифровизация образования и рост спроса на научные веб-инструменты (browser-first science).
- ML-методы всё активнее применяются для предсказания структуры и свойств материалов
  (MLIP, графовые нейросети), но лёгких открытых демо «нейросеть предсказывает связи в
  решётке в реальном времени» мало.
- Задача на стыке трёх востребованных компетенций: WebGL/3D-графика, backend-вычисления
  (FastAPI, ASE, SciPy) и глубокое обучение (PyTorch).

## 4. Цель

Создать клиент-серверное веб-приложение, позволяющее:

1. визуализировать кристаллические решётки (FCC, BCC, SC, Diamond, HCP) типовых элементов
   (Cu, Al, Fe, C, Si, Au, Ag) в интерактивном 3D;
2. предсказывать химические связи натренированной нейросетью, а не только геометрическим
   порогом;
3. моделировать реакцию: внедрять атомы чужеродного вещества в решётку-хозяин и наблюдать
   изменение структуры во времени с выделением получившихся «веществ» (связных компонент
   графа связей).

## 5. Задачи

### Архитектура и backend
- [x] Развернуть backend на FastAPI, описать схемы данных через Pydantic.
- [x] Генерация решёток с помощью ASE (`bulk`), поддержка типов FCC/BCC/SC/Diamond/HCP.
- [x] Геометрический baseline расчёта связей через KD-дерево (SciPy `cKDTree`).
- [x] Реализовать MLP-модель предсказания связей (`backend/model.py`, PyTorch):
      признаки пары — ковалентные радиусы, электроотрицательности, one-hot элемента,
      расстояние и отношение расстояния к сумме радиусов; обучение на синтетических
      данных из физических правил (~40 000 примеров, accuracy ≈ 0.98).
- [x] Автотренировка модели при первом запуске, сохранение весов в `bond_model.pt`,
      endpoint перетренировки `/api/train_model` и диагностики `/api/model_info`.
- [x] Graceful degradation: при отсутствии torch сервер работает на геометрическом алгоритме.
- [x] Endpoint'ы: `/api/atoms`, `/api/elements`, `/api/sites`, `/api/substitute`,
      `/api/predict_bonds`, `/api/reaction`, `/api/train_model`, `/api/model_info`.

### Алгоритмы анализа структуры
- [x] Поиск кандидатов на связь и предсказание вероятностей нейросетью.
- [x] Выделение связных компонент графа связей (Union-Find, `detect_molecules`) →
      формулы получившихся «веществ» (например, CuₙO).
- [x] Симуляция реакции с временной шкалой: шумовые возмущения позиций по кадрам,
      пересчёт связей и молекул на каждом кадре (`/api/reaction`).

### Frontend
- [x] React 19 + Vite, 3D-сцена на Three.js / React Three Fiber, UI на Material UI.
- [x] Панель параметров: элемент, тип решётки, размер, плоскость среза, цвет, показ связей,
      светлый/тёмный фон.
- [x] Добавление атомов другого вещества кликом в центр куба или в любую точку сцены.
- [x] Отображение результатов предсказания связей и покадровой симуляции реакции.

### Инфраструктура
- [x] CORS-настройки для раздельного запуска frontend/backend.
- [x] Документация (README.md), лицензия MIT.

## 6. Что сделали (итоги реализации)

Полностью работающий прототип (MVP+): backend ~540 строк (`main.py`) + модель (~190 строк),
frontend ~810 строк (`App.jsx`). Решётки генерируются, связи предсказываются нейросетью с
выводом вероятностей, реакция со временем раскладывается на кадры, продукты автоматически
распознаются как связные компоненты с химическими формулами. Модель тренируется автоматически
и достигает accuracy ≈ 0.98 на синтетическом тесте. Собран production-bundle фронтенда (`dist/`).

## 8. Финальные мысли

Проект показывает, что лёгкое веб-приложение может объединить кристаллографию, 3D-графику и
машинное обучение в единый исследовательско-образовательный инструмент. Ключевой вывод: даже
компактный MLP, обученный на физически мотивированных синтетических данных, заметно умнее
геометрического порога и хорошо переносит связи на смешанные системы — это делает «нейросеть
как движок химической интуиции» практичным паттерном. Дальнейший путь — движение к реальным
датасетам и GNN/потенциалам, чтобы приближаться к количественно корректному моделированию
материалов, сохраняя при этом мгновенную интерактивность в браузере. Инструмент уже сегодня
пригоден как наглядная песочница для изучения defect-химии и кристаллической структуры.
