# РЕФЕРАТ

**Выпускная квалификационная работа** по теме: «Программа для 3D-визуализации
кристаллических структур с интеллектуальным анализом на основе машинного обучения»
(Crystal Lattice Visualization)

**Объём работы:** пояснительная записка — ___ стр., ___ рисунков, ___ источников,
___ приложений; исходный код проекта (backend ~730 стр. Python, frontend ~810 стр. JS/JSX).

**Ключевые слова:** кристаллическая решётка, визуализация атомных структур, WebGL,
Three.js, React, FastAPI, ASE, машинное обучение, предсказание межатомных связей,
нейросеть, связные компоненты графа, молекулярная динамика, образовательные
инструменты, физика конденсированного состояния.

---

## Аннотация

Работа посвящена разработке клиент-серверного веб-приложения для интерактивной
3D-визуализации кристаллических решёток и интеллектуального анализа их структуры
методами машинного обучения. Приложение предназначено для использования в учебном
процессе и в исследовательской практике как лёгкая альтернатива сложным научным
пакетам (VESTA, Ovito), не требующим от пользователя высокой квалификации.

**Актуальность** работы обусловлена цифровизацией образования и ростом спроса на
научные веб-инструменты (browser-first science), а также широким внедрением
ML-методов в материаловедение при недостатке открытых демонстрационных решений,
показывающих работу нейросети, предсказывающей связи в решётке в реальном времени.

**Цель работы** — создать клиент-серверное веб-приложение, объединяющее
трёхмерную визуализацию кристаллических структур, генерацию атомных конфигураций
и нейросетевой анализ межатомных взаимодействий.

Для достижения цели решены шесть групп задач (46 подзадач): визуализация типовых
решёток (FCC, BCC, SC, Diamond, HCP) для элементов Cu, Al, Fe, C, Si, Au, Ag;
адаптация приложения к смешанным системам (Ni–Al, Ti–Al) с замещением атомов;
реализация создания и обучения ИИ-модели путём загрузки обучающей выборки;
разработка серверного модуля генерации структур и единого REST API; алгоритм
выделения связных компонент графа связей для идентификации образующихся «веществ»
с выводом химических формул; моделирование эволюции структуры во времени с
покадровой перестройкой связей.

## Методы и технологии

Backend реализован на FastAPI (Python) с использованием библиотеки ASE для
генерации объёмных структур, SciPy (cKDTree) — для геометрического поиска
кандидатов на связь, Pydantic — для контрактных схем данных. Модель предсказания
связей — многослойный перцептрон (MLP) на PyTorch; признаки пары атомов включают
ковалентные радиусы, электроотрицательности, one-hot код элемента, расстояние и
его отношение к сумме радиусов. Обучение выполняется на синтетических данных,
сгенерированных из физических правил (~40 000 примеров), с автоматической
тренировкой при первом запуске и сохранением весов. Выделение молекул основано на
алгоритме Union-Find для поиска связных компонент графа с учётом периодических
границ ячейки; формулы компонентов сортируются по холловскому порядку.

Frontend построен на React 19 + Vite, трёхмерная сцена — на Three.js / React
Three Fiber, интерфейс — на Material UI. Поддержаны орбитальная камера, настройка
размера и цвета атомов, плоскость среза (clip plane), светлый/тёмный фон, панель
параметров, плеер покадровой анимации реакции с интерполяцией позиций атомов.

## Основные результаты

Разработан полностью функционирующий прототип приложения уровня MVP+:
- генерация и корректная визуализация пяти типов решёток и суперъячеек заданного размера;
- замещение атомов в смешанных системах (Ni–Al, Ti–Al) в случайном и детерминированном режимах;
- нейросетевое предсказание связей с точностью accuracy ≈ 0,98 на синтетическом
  тестовом множестве и graceful degradation на геометрический алгоритм при
  отсутствии PyTorch;
- восемь REST endpoint'ов (`/api/atoms`, `/api/elements`, `/api/sites`,
  `/api/substitute`, `/api/predict_bonds`, `/api/reaction`, `/api/train_model`,
  `/api/model_info`);
- автоматическое распознавание продуктов реакции как связных компонент с
  химическими формулами (например, CuₙO) и их отображение в интерфейсе;
- симуляция эволюции структуры во времени (шумовые возмущения по кадрам) с
  пересчётом связей и состава продуктов на каждом кадре;
- собранный production-bundle фронтенда, документация, лицензия MIT.

## Практическая значимость

Приложение применимо как наглядный образовательный инструмент для изучения
кристаллического строения и дефектной химии, а также как песочница для быстрой
проверки разработанных ИИ-моделей на структурах, смоделированных методом
молекулярной динамики. Ключевой вывод работы: компактный MLP, обученный на
физически мотивированных данных, существенно превосходит геометрический порог
расстояния и хорошо переносит предсказание связей на смешанные системы, что делает
паттерн «нейросеть как движок химической интуиции» практичным решением.

## Структура работы

Пояснительная записка включает: введение (постановка проблемы, актуальность, цель
и задачи), обзор предметной области и существующих инструментов, описание
архитектуры клиент-серверного приложения, главы о генерации структур и API,
нейросетевой модели предсказания связей, алгоритмах анализа графа связей и
моделировании динамики, руководство пользователя и разработчика, заключение и
планы развития (переход к реальным датасетам Materials Project/ICSD, графовые
нейросети и обучаемые потенциалы в духе MACE/NequIP, экспорт CIF/XYZ/POSCAR,
тестирование, CI/CD и контейнеризация).
