КРИСТАЛЛИЧЕСКАЯ РЕШЁТКА, ТРЁХМЕРНАЯ ВИЗУАЛИЗАЦИЯ, WEBGL, THREE.JS,
REACT, FASTAPI, МАШИННОЕ ОБУЧЕНИЕ, ПРЕДСКАЗАНИЕ МЕЖАТОМНЫХ СВЯЗЕЙ,
ГРАФ СВЯЗНОСТИ, МОЛЕКУЛЯРНАЯ ДИНАМИКА.

Работа посвящена разработке клиент-серверного веб-приложения для
интерактивной трёхмерной визуализации кристаллических решёток и
интеллектуального анализа их структуры методами машинного обучения.
Рассматриваются типовые решётки (FCC, BCC, SC, Diamond, HCP) элементов Cu,
Al, Fe, C, Si, Au, Ag и смешанные системы (Ni–Al, Ti–Al) с замещением
атомов. Обосновывается выбор архитектуры «тонкий клиент — вычислительный
сервер» и стека технологий (React, Three.js, FastAPI, ASE, SciPy, PyTorch)
для задач browser-first science; описываются генератор атомных
конфигураций, единый REST API и многослойный перцептрон предсказания
межатомных связей на физически мотивированных признаках пары атомов.
Программой экспериментов подтверждено превосходство обученной модели
(accuracy ≈ 0,98) над геометрическим порогом расстояния на смешанных
системах. Результатом работы является функционирующий прототип
приложения уровня MVP+, снижающий порог входа в изучение кристаллического
строения для студентов и служащий песочницей для быстрой проверки
разработанных ИИ-моделей на структурах, полученных методом молекулярной
динамики.

Отчёт оформлен с помощью системы компьютерной вёрстки LibreOffice Writer.
